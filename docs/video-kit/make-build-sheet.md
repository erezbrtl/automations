# דף בנייה - Make

סדר הלחיצות בדיוק כפי שתעשה אותן בהקלטה, עם כל ערך מוכן להדבקה.
הדפס או פתח במסך שני. **אל תאלתר תוך כדי - כל שדה כאן נבחר כדי שייראה טוב על המסך.**

---

## מודול 1 - Webhooks › Custom webhook

| שדה | ערך |
|---|---|
| Webhook name | `ליד מהאתר` |
| Data structure | Generate automatically (שלח פנייה אחת מהטופס והוא ילמד לבד) |

לחץ **Copy address to clipboard**, הדבק בטופס הבדיקה, שלח פנייה אחת, וחזור.
Make יראה *Successfully determined*. זה השלב היחיד שדורש קפיצה לטאב אחר -
תעשה אותו **לפני** ההקלטה ותשאיר את התרחיש עם המודול הראשון בלבד.

---

## מודול 2 - OpenAI / Anthropic › Create a completion

| שדה | ערך |
|---|---|
| Model | `gpt-4o-mini` |
| Temperature | `0.3` |
| Max tokens | `400` |

הודעה ראשונה - תפקיד **System**: הדבק את בלוק ה-System מתוך `ai-prompt.md`.

הודעה שנייה - תפקיד **User**:

```
שם: {{1.name}}
טלפון: {{1.phone}}
תוכן הפנייה: {{1.message}}
```

---

## מודול 3 - JSON › Parse JSON

| שדה | ערך |
|---|---|
| JSON string | `{{2.choices[].message.content}}` |
| Data structure | Generate → הדבק דוגמת פלט מ-`ai-prompt.md` |

בזכות המודול הזה השדות הבאים נבחרים מרשימה במקום להיכתב ביד - נראה מקצועי ולא נתקע.

## מודול 4 - Google Sheets › Add a row

| עמודה | ערך |
|---|---|
| תאריך | `{{formatDate(now; "DD/MM/YYYY HH:mm")}}` |
| שם | `{{1.name}}` |
| טלפון | `{{1.phone}}` |
| נושא | `{{3.topic}}` |
| דחיפות | `{{3.urgency}}` |
| סיכום | `{{3.summary}}` |
| תשובה שנשלחה | `{{3.reply}}` |

הגיליון: ייבא את `leads-sheet.csv` - הכותרות כבר בסדר הנכון.

## מודול 5 - Gmail › Send an email

| שדה | ערך |
|---|---|
| To | `{{1.email}}` (בהקלטה: כתובת בדיקה שלך) |
| Subject | `קיבלתי את הפנייה שלך` |
| Content | `{{3.reply}}` |

> רוצה וואטסאפ במקום מייל? זה נראה חזק יותר בסרטון אבל דורש WhatsApp Business API.
> אם אין - **תישאר עם מייל.** תקלה בהקלטה שווה יותר מאפקט.
