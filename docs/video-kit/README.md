# ערכת ההקלטה

כל מה שצריך כדי להקליט את סרטון ההירו בטייק אחד, בלי לחשוב תוך כדי.

| קובץ | מה זה |
|---|---|
| `../video-script.md` | התסריט המלא עם התזמונים |
| `teleprompter.html` | טלפרומפטר: שורה אחת גדולה בכל פעם, טיימר, רווח לשלב הבא |
| `ai-prompt.md` | הפרומפט למודול ה-AI, מוכן להדבקה, עם דוגמאות פלט |
| `make-build-sheet.md` | סדר הלחיצות ב-Make עם כל ערך להדבקה |
| `n8n-workflow.json` | אותו תרחיש כקובץ ייבוא ל-n8n |
| `leads-sheet.csv` | כותרות הגיליון בסדר הנכון |
| `test-leads.md` | לידים בדויים לבדיקה יבשה ולהקלטה |

## סדר העבודה

**יום לפני**

1. ייבא את `leads-sheet.csv` ל-Google Sheets, קרא לגיליון "לידים".
2. חבר ב-Make את החשבונות: Google Sheets, Gmail, ומודול ה-AI.
3. בנה את התרחיש פעם אחת לפי `make-build-sheet.md` עד שהוא עובד.
4. הרץ את שלושת הלידים מ-`test-leads.md` ותוודא שה-JSON חוזר נקי.
5. **מחק את התרחיש.** משאירים רק את המודול הראשון עם ה-webhook שכבר למד את המבנה.

**ביום ההקלטה**

1. פתח את הטלפרומפטר במסך שני (או בטלפון על חצובה).
2. דפדפן נקי, זום 125%, בלי התראות.
3. הקלט שלוש פעמים ברצף. קח את השני.

## למה n8n ולא רק Make

שני הקבצים מתארים את אותו תרחיש. `n8n-workflow.json` הוא ייבוא ישיר -
אחרי הייבוא צריך רק לבחור Credentials בכל צומת ולהדביק את מזהה הגיליון.
ל-Make אין קובץ ייבוא כאן בכוונה: פורמט ה-Blueprint משתנה בין גרסאות,
ו-`make-build-sheet.md` הוא מה שבאמת עוזר תוך כדי הקלטה - שדה, ערך, הבא.
