## הליד של הסרטון (זה שתשלח בשידור חי)

```
שם: רונית לוי
טלפון: 052-0000000
פנייה: רוצה הצעת מחיר לשיפוץ מטבח, דחוף להשבוע
```

נבחר בכוונה: יש בו נושא ברור **וגם** מילת דחיפות, כך שמודול ה-AI מחזיר
`topic` ו-`urgency` שונים זה מזה - והצופה מבין בשנייה שהמכונה באמת הבינה משהו.
